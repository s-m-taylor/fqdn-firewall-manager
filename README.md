# FQDN Windows Firewall Manager

This is a tool for managing Windows Firewall Dynamic Keyword Addresses on outbound allow firewall rules. In a default deny 
environment this tool will allow you to assign/view/remove FQDNs to outbound allow rules for better control.

This project was built with [Lovable](https://lovable.dev).
