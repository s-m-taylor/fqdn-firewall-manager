# FQDN Firewall Manager

I am converting my PowerShell tool (FqdnFirewallGui.ps1) for managing Windows Firewall Dynamic Keyword Addresses into a standalone C# .NET 8 WPF application. Please generate all project files (FqdnFirewallManager.csproj, app.manifest, Models/Models.cs, Services/FirewallService.cs, MainWindow.xaml, MainWindow.xaml.cs, and build instructions) and package them into a downloadable zip file artifact.

This project was built with [Lovable](https://lovable.dev).
